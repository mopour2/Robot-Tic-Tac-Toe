In this experiment, a simple interactive game was created where a robotic arm plays Tic-Tac-Toe with a human participant. A camera observes the gameboard, while an AI-based decision method determines how the robot responds. The robotic arm used a suction device to move colored cubes onto the board. The system combines visual recognition and motion planning to show how a low-cost robot can demonstrate intelligent behavior. This study  explore the connection between computer vision, AI decision-making, and robotic motion control in a simple, engaging form
